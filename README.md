## A customizable 2D and 3D game engine

**ExpoCore** is a game engine project based on the open-source [Godot Engine](https://github.com/godotengine/godot). It aims to build on Godot's 2D and 3D development tools while creating its own identity and evolving features.

This repository currently contains the Godot engine source code. ExpoCore-specific changes and features will be developed here over time.

## Project goals

- Build a distinct game-engine identity around the Godot foundation.
- Customize the editor and development experience.
- Explore engine improvements and new workflows.
- Preserve useful cross-platform 2D and 3D capabilities.

## Building from source

ExpoCore currently follows Godot's source build process.

See the [Godot engine compilation documentation](https://docs.godotengine.org/en/latest/engine_details/development/compiling/) for platform-specific requirements and instructions.
